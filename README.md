# 🪐 Órbita Kids

**Órbita Kids** es un proyecto educativo diseñado para reforzar el aprendizaje de **matemáticas en niños de los primeros grados de primaria**.

A través de una aventura espacial, el estudiante ayudará a un personaje a **explorar planetas, superar misiones y reparar su nave** mientras resuelve actividades matemáticas de forma interactiva.

---

## 🎯 Objetivo

Desarrollar una herramienta educativa que apoye el aprendizaje de matemáticas mediante actividades interactivas capaces de **adaptar su dificultad según los errores y avances del estudiante**.

La temática espacial funciona como apoyo visual y motivacional, manteniendo siempre como prioridad el **aprendizaje y refuerzo educativo**.

---

## 🚀 ¿Cómo funciona?

### 👨‍🚀 Aplicación para estudiantes

Desarrollada con **Flutter**, permitirá al estudiante:

- Elegir un personaje.
- Resolver actividades matemáticas.
- Explorar diferentes planetas y niveles.
- Obtener recompensas visuales.
- Consultar su progreso.
- Recibir ejercicios adaptados a su desempeño.

### 👩‍🏫 PWA para docentes

Desarrollada con **React**, permitirá al docente:

- Administrar grupos y estudiantes.
- Asignar actividades.
- Consultar el progreso de los alumnos.
- Identificar ejercicios o temas que necesitan mayor refuerzo.

### 🧠 Adaptación de actividades

El sistema utilizará **reglas programadas** para modificar la dificultad de los ejercicios.

Por ejemplo, si un estudiante presenta errores frecuentes en determinadas sumas, el sistema podrá ofrecer:

- Ejercicios más sencillos.
- Mayor apoyo visual.
- Actividades de refuerzo.

Cuando el estudiante mejore, la dificultad podrá aumentar progresivamente.

---

## 📚 Primera versión

La primera versión de **Órbita Kids** estará enfocada en:

- ➕ Tema principal: **sumas**.
- 🪐 **3 niveles** de dificultad.
- 🧩 **2 tipos de actividades**.
- ⭐ Sistema básico de progreso.
- 🎁 Recompensas visuales.
- 👨‍🚀 Selección de personaje.
- 🗺️ Mapa de niveles o planetas.
- 📈 Adaptación básica según el desempeño.

La aplicación móvil y la PWA estarán conectadas mediante una **API REST desarrollada con FastAPI**, utilizando **PostgreSQL** para almacenar la información del sistema.

> Actualmente, estas aplicaciones forman parte de la propuesta general del proyecto. La **Práctica 04** se centra en el desarrollo del **Modelo de Negocio Canvas interactivo de Órbita Kids**.
