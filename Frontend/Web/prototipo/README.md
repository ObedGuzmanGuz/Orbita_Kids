## Pestañas

| Pestaña | Qué muestra |
|---|---|
| **Prototipo** | La ventana navegable con el índice de pantallas y la ficha de cada una. Controles de **ventana** (navegador o app instalada), **ancho** (1280, 1024, 820), **conexión**, **tema** y «Ver en acción». |
| **Sketches** | Los sketches de cada estado con su ficha. |
| **Wireframes** | Los wireframes con capas (rejilla, medidas, números) y la especificación de cada estado. |
| **Diagramas de secuencia** | 4 flujos clave; los pasos con código de pantalla abren el prototipo en ese estado. |
