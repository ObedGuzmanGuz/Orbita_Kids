# Sketches · Órbita Kids

Bocetos de **baja fidelidad** dibujados a lápiz (estilo a mano con rough.js). Hay **130 sketches** de **60 pantallas**: uno por pantalla y uno más por cada estado que cambia con una acción. Cada caja, texto, imagen y botón tiene la misma posición y tamaño que en el wireframe y en el prototipo.

## Cómo leerlos

| Símbolo | Significado |
|---|---|
| Círculo rojo con número | Acción que se puede tocar (se describe en la tabla) |
| Rectángulo con una X | Imagen o ilustración (astronauta, Orbi, planeta, logotipo) |
| Círculo con relleno en zigzag | Planeta |
| Rayado diagonal | Zona con fondo oscuro (encabezados espaciales, splash) |
| Línea punteada | Elemento secundario o desactivado |
| Rayas detrás de una capa | Fondo oscurecido por un diálogo u hoja inferior |

Encima de cada sketch está su código, el nombre de la pantalla y, en rojo, el estado.
