1 · Unidades por tecnología

App móvil Flutter · lp

  • Píxeles lógicos (lp = dp). Todas las cifras de los wireframes móviles se usan tal cual en SizedBox, EdgeInsets, BorderRadius y TextStyle(fontSize).
  • No convertir a píxeles físicos. Flutter multiplica por devicePixelRatio automáticamente.
  • Lienzo base 375×812 lp. En pantallas más anchas, el cuerpo se estira (Expanded) y se conservan paddings, gaps, radios y alturas.
  • Alto de línea: height = lineHeight ÷ fontSize (ej.: 13/18 → height: 18/13).
  • Áreas táctiles mínimas de 48×48 lp aunque el elemento visible sea menor (avatar 32, switch 44×24).

Web / PWA React + Vite · px / rem

  • px CSS en los wireframes; en código usar rem = px ÷ 16 con html { font-size: 100% }.
  • Ejemplos: 8px = 0.5rem · 12px = 0.75rem · 16px = 1rem · 24px = 1.5rem · 48px = 3rem · 260px = 16.25rem · 972px = 60.75rem.
  • Lienzo base 1280×800 px. El main usa grid de 12 columnas (59px · gutter 24px); los anchos de tarjeta salen de columnas, no de valores fijos.
  • Anchos con decimales (ej. 127.43, 165.5) indican fracciones: implementar con 1fr / flex: 1, no como valores fijos.
  • Bordes de 1px se mantienen en px (no escalan con rem).

6 · Cómo leer las cotas de las imágenes

  • Negro, fuera del marco: lienzo, regiones (barra de estado, AppBar, header, sidebar) y alto de cada bloque.
  • Rojo: medidas de cada elemento. W×H rN = ancho × alto y radio; Ø = diámetro; □24 = icono de 24; ×N = repetido idéntico.
  • Flechas rojas cortas: padding interno (izquierda y arriba; derecha/abajo solo si difieren) y separaciones (gap) entre hermanos y entre bloques.
  • Aa13/18 B = font-size 13, line-height 18, peso 700.
  • Las barras grises representan texto; su largo es ilustrativo. El ancho que cuenta es el del contenedor (columna «Ancho» = máximo disponible, o «auto»).
  • Las imágenes «sin medidas» (assets/wireframes/…/limpio/) son la misma pantalla sin cotas, para revisión visual.
  • Todas las cifras salen de tools/: si cambias un token, ejecuta build.py y export_specs.py y se regeneran imágenes, tablas y tokens.
