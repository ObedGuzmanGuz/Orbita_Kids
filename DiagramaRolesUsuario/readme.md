# 🚀 Práctica 05 · Diagrama de Roles de Usuario | Órbita Kids

## 📌 Descripción

En esta práctica se desarrolló un **Diagrama de Roles de Usuario** para el proyecto **Órbita Kids**, una plataforma educativa de matemáticas.

El diagrama representa la interacción entre los principales actores de la plataforma, el núcleo del sistema y sus funcionalidades principales.

### 👥 Roles identificados

- 👨‍🎓 **Estudiante**
  - Utiliza la aplicación móvil.
  - Resuelve actividades matemáticas.
  - Avanza en la misión espacial.
  - Consulta su progreso.

- 👨‍🏫 **Docente**
  - Utiliza la PWA docente.
  - Administra grupos.
  - Asigna actividades.
  - Consulta resultados y progreso.

- 🏫 **Escuela / Institución**
  - Representa el contexto institucional de adopción.
  - Participa en pilotos, demostraciones y licencias.

### ⚙️ Funcionalidades principales

1. **Actividades matemáticas**
2. **Refuerzo adaptado**
3. **Progreso y misión espacial**
4. **Grupos y asignaciones**
5. **Resultados y seguimiento**

## 🖥️ Características

El diagrama cuenta con una interfaz interactiva que permite:

- Explorar los diferentes roles de usuario.
- Consultar las funcionalidades de la plataforma.
- Visualizar la relación entre actores y funcionalidades.
- Abrir fichas con información detallada.
- Navegar entre los diferentes elementos.
- Pausar o reanudar las animaciones.
- Imprimir el diagrama.
- Utilizar el contenido mediante navegación accesible.
